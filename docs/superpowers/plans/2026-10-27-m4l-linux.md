# M4-L: Linux in v1.0 (record)

User decision U-LNX1 (2026-10-27, spec §17) brings Linux into v1.0. It runs after M4's release
candidate and before the publication (M4 Task 12). Windows behaviour stays unchanged; Linux code
lives in `*_gtk.cpp` files, `__WXGTK__` / `!_WIN32` blocks and the CMake non-Windows branches.

## Changes during execution
- The Linux GUI does not change `GDK_BACKEND` while GTK's threads run; it calls
  `gdk_set_allowed_backends("x11")` and replaces only a `GDK_BACKEND` the user set (L1).
- `tools/sanity.sh` checks every cloned repository without `--repo`, instead of the change
  detection of `sanity.ps1`: git status from WSL on a tree checked out by Windows git is
  unreliable (L5).
- Not validated locally: the Xvfb path (Xvfb not installed in WSL), the clean-container check (no
  local Docker), scales other than 1x. CI covers the first two at the first dry run.

## Stays v1.x
Native Wayland, the Linux file-I/O default review, the Linux frame-timer jitter check, a Linux crash
handler and the AppImage.
